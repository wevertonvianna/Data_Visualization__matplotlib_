# 📊 Imigração Sul-Americana para o Canadá (1980–2013)

Este repositório é um exercício de **data visualization** com foco em dados de imigração de países da América do Sul para o Canadá entre os anos de 1980 e 2013.

## 🔍 Objetivo

O objetivo deste projeto é praticar a criação de gráficos com **Matplotlib** e explorar visualmente os dados de imigração, destacando:

- O total de imigrantes de países sul-americanos para o Canadá no período de 1980 a 2013.
- A evolução da imigração do Brasil para o Canadá ao longo do tempo.
